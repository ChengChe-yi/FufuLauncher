# 米游社社区窗口

入口：工具面板 → 社区 → 米游社，与 VanillaBBS 并列。窗口复用启动器的 Mica、主题资源、卡片与标题栏。

界面参考小黑盒网页端的信息流和帖子阅读层级：只保留一层侧栏与一层顶部工具栏；版块和排序胶囊放在顶栏，窗口较窄时横向滚动。帖子列表在主区域居中展示，点开后正文占满主区域；左上角返回按钮、Esc、Alt+左箭头、浏览器后退键及非输入框中的 Backspace 可返回，恢复列表筛选和滚动位置。收藏、复制链接、打开原帖和“右侧评论”开关集中在标题右侧，不再堆叠正文/评论切换。评论默认接在正文下方，与正文共用滚动条；打开“右侧评论”后，评论在右侧栏独立滚动。两种布局共用已加载的评论和排序状态，切换布局不重新请求，也不重新加载正文图片。左下角不再显示致谢入口，MIT 许可仍随程序输出。

## 功能

- 动态获取游戏分区和版块，支持热门、最新发布、最新回复排序。
- 官方资讯、公告、活动；关键词搜索；直接打开帖子 ID 或米游社帖子/用户/话题/合集链接。
- 帖子富文本、标题层级、原文链接、图片预览、视频播放；作者主页、话题和合集导航。
- 热门、最新、最早评论，只看楼主，分页和楼中楼回复。
- 复用启动器国服账号读取关注动态、米游社收藏和个人主页。账号选择仅作用于此窗口。
- 本地收藏、最近 200 条去重浏览记录、复制帖子链接、打开官方原帖。
- 使用已选国服账号为帖子、评论点赞/取消点赞，发表评论和楼中楼文字回复；下置评论和右侧评论都提供互动入口。

发帖、图片评论、投票、抽奖等功能保留官方原帖入口。启动器已有的游戏战绩、便笺、背包等功能继续使用各自模块。

## 参考与协议

参考 [TeyvatGuide](https://github.com/BTMuli/TeyvatGuide)，版本 `38d48e9117a7d6b10586dbe28089f3954ee82045`：

| 来源 | 应用方式 |
| --- | --- |
| `src/request/painterReq.ts` | 版块、资讯和关注动态接口及参数 |
| `src/request/postReq.ts` | 搜索、详情、评论、用户、话题、合集和收藏接口 |
| `src/request/bbsReq.ts` / `topicReq.ts` | 用户、话题、合集资料 |
| `src/utils/getRequestHeader.ts` / `TGBbs.ts` | 按接口选择 DS1/DS2、X4/K2、client_type 和版本 |
| `src/request/miscReq.ts` / `src/components/func/geetest.vue` | 官方创建验证码 → 用户验证 → 提交验证结果 → 携带 challenge 重试；支持极验 V3/V4 |
| `src/components/viewPost` | 结构化正文、图片和视频的呈现方式 |
| `src/request/apiHubReq.ts` | 帖子点赞接口、K2/DS1 签名及取消点赞参数 |

评论发布和评论点赞参数另核对了[米游社官方网页脚本](https://www.miyoushe.com/_static/e901ffb.js)：`post/wapi/releaseReply` 使用纯文本、Quill insert 数组、游戏 gids 和可选 reply_id；`apihub/api/upvoteReply` 使用 post_id、reply_id 和 is_cancel。2026-10-02 排查发布评论的 `invalid request`，发现之前误用了 X4/client_type=5。对照网页请求模块与[网页签名模块](https://www.miyoushe.com/_static/1125a5d.js)，评论改为网页 client_type=4、app_version=2.102.0、网页 salt 的 DS1，使用网页 Origin/Referer 和持久化设备身份；对应验证码创建和验证也保持同一档案。真实发布仍需用户手动验证。

这是 C#/WinUI 实现，无需 Tauri、Node 或 Rust 运行环境。沿用项目已依赖的 HtmlAgilityPack、WebView2 和 WinUIEx。参考项目的 MIT 许可随程序输出至 `Licenses/TeyvatGuide.txt`。

## 风控处理

- 国服登录请求使用 `AccountIdentityService` 的真实、持久化设备身份；指纹缺失时切换游客并提示重新登录。不会制造随机指纹填补失败。
- 无需登录的公共接口不发送账号 Cookie。优先继承同一账号的完整 V2 凭据：ltoken_v2/ltuid_v2/ltmid_v2 与 cookie_token_v2/account_id_v2/account_mid_v2；V2 不完整时整组回退 V1，避免混用两代字段或其他账号的 ID。关注动态只发送 LToken 一组，其他账号接口不发送 stoken 和原始 mid。
- 签名档案独立于启动器其他米哈游服务；查询和点赞使用参考版本 2.115.0，评论提交使用上述官方网页签名档案。协议常量需随官方变化维护。
- 1028/1034、带 `x-rpc-aigis` 的响应和 HTTP 403/412 暂停此会话的后续请求。用户主动选择验证，取消后保持暂停。
- 验证页面使用官方极验 SDK，既支持社区 challenge，也支持 Aigis session。成功证明只附着到触发验证的同一请求，并且仅使用一次；重复风控再次暂停。
- 不自动刷新、抓取后续页或循环重试。请求串行且间隔至少 650ms；HTTP 429 遵守 Retry-After（最长 300 秒）；完整响应设 25 秒期限和 8 MiB 上限。
- 切换列表、帖子、账号和关闭窗口会取消旧请求。账号过期提示重新登录，不静默更换身份。
- 写入操作不会自动重试；点赞请求使用明确的目标状态，成功后更新界面。发表评论需用户点击“发布到米游社”，风控时由用户点击“验证并发布”；验证证明继续匹配同一请求正文。草稿按账号、帖子和回复目标隔离，仅在窗口内存保留，成功后才清空。发送后断连、超时、取消或响应格式异常提示结果无法确认，保留草稿并要求先检查原帖，避免重复发布；不将发布操作交给通用重试按钮。
- 正文与下置评论只渲染清理后的本地 HTML，页面脚本、iframe、表单、WebMessage 和宿主对象保持禁用；账号凭据不进入正文 WebView。启动器通过固定的 ExecuteScriptAsync 代码更新已编码的评论片段，并核对完整的当前本地文档地址；这不启用帖子脚本。评论排序、分页与楼中楼链接使用每篇帖子的随机路径，只在当前文档内交回启动器处理。外部链接仅由用户点击打开。

## 验证

```powershell
dotnet restore tests/Miyoushe.Tests --source https://api.nuget.org/v3/index.json
dotnet run --project tests/Miyoushe.Tests --no-restore
# 可选：只读公开接口检查，不读取本地账号
dotnet run --project tests/Miyoushe.Tests --no-restore -- --live
```

覆盖签名、Cookie 隔离、稳定设备头、富文本清理/字号/链接、中文 URL 边界、图集附件、风控暂停/取消/单次证明、限流、本地持久化、点赞目标、评论正文/回复目标、游客限制、发布结果不明确时不自动重发。写入接口用本地模拟响应验证，测试不会使用真实账号点赞或发布评论。

2026-10-02 使用 Computer Use 检查真实窗口，已确认普通图文帖与图集帖的正文图片、说明文字和点击图片预览可见。正文使用本地生成的完整 data URI 精确放行，避免被外部链接拦截器取消；图集附件从 `image_list` 补全并去重。实际极验完成仍需在对应账号与风控场景中验收。

同日排查登录继承问题：本地账号同时保留 V1/V2 Cookie，旧 LToken 请求返回 -100；缺少 ltmid_v2 的 V2 请求也返回 -100。补齐绑定字段后，用社区客户端实际代码只读验证关注动态、收藏和个人主页；没有进行真实点赞或评论提交。切换页面时清除上一页的普通错误提示，安全验证暂停状态继续保留。
